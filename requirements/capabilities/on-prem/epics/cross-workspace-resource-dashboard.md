# Cross-Workspace Resource Allocation Dashboard

## Overview
Provide platform engineers with a unified dashboard to view CPU, memory, storage, and network utilization for on-prem GreenLake deployments across customer accounts.

## Goals
- Aggregate utilization metrics across all on-prem clusters
- Surface anomalies and capacity-warning thresholds
- Allow drill-down to per-host metrics

## Success Criteria
- 99% data freshness within 5 minutes
- Dashboard loads in under 3 seconds for 500+ hosts
